# ICP:各行業買方訊號 + 跟進打法

評分時對照本檔 + CLAUDE.md 公司背景。「明確買方訊號」= A 級候選;「間接訊號」= B 級候選。

## ⚡ 通用最高優先訊號(跨行業,直接列 A 級候選)

- **目標行業公司被 DDoS 攻擊或大規模宕機(近 3 天內)** → 對方正在痛,是最強的採購時機。
  - 切入:高防、快速遷移、備援節點;24–48 小時內接觸效果最好。
- 主流雲/CDN(AWS、Cloudflare、Akamai 等)公告收緊政策、漲價、或拒收某類內容 → 整批受影響客戶都是候選。

## 🎰 iGaming(博彩)

### 買方訊號(強 → 弱)
1. **拿到新牌照**:巴西、菲律賓(PAGCOR)、馬爾他(MGA)、庫拉索(Curaçao)→ 即將上線/擴張,必採購基礎設施。
2. **宣布進軍新市場**(拉美、非洲、東南亞)→ 需要當地節點覆蓋。
3. **賽季前擴容**:世界盃、歐冠、NFL 賽季前 → 流量高峰採購窗口。
4. **被 DDoS 攻擊**(博彩業最常見)→ 立刻要高防。
5. **原供應商拒收博彩業務** / 被主流雲清退 → 被迫遷移。

### 跟進打法
- **管道**:Telegram / Skype 為主(此行業慣用),Email 為輔。
- **信任建立**:展會為主 —— SiGMA(馬爾他/巴西/馬尼拉)、SBC Summit、G2E Asia。
- **話術核心**:直接談「**我們接受博彩業務 + 高防 DDoS + 目標市場節點覆蓋**」,不繞彎。
- **決策人**:CTO / Head of Infrastructure。

## 🤖 AI

### 買方訊號(強 → 弱)
1. **剛完成融資(Seed–B 輪最理想)**→ 有錢、infra 尚未定型、對成本敏感。
2. **推出 C 端產品**(聊天、生圖、生影片、陪伴類)→ 流量與推理成本暴增。
3. **招聘 infra / MLOps / GPU 相關職缺** → 正在建基礎設施。
4. **公開抱怨 GPU 短缺或雲成本太高**(創辦人推文、HN、Reddit)→ 直接痛點。

### 跟進打法
- **管道**:LinkedIn + Email(創辦人/CTO 通常可直達)。
- **話術核心**:與 AWS/GCP 的**成本對比**(算給他看)+ **GPU 供給能力**。
- **決策人**:CTO / 創辦人。

## 🔞 成人

### 買方訊號(強 → 弱)
1. **新平台上線**(Fansly 類訂閱制、直播、AI 成人應用)。
2. **大站更換 CDN / 主機供應商**(從流出的技術訊息、行業報導判斷)。
3. **主流雲/CDN/支付收緊成人內容政策** → 整批客戶被迫尋找替代方案。

### 跟進打法
- **話術核心**:「**我們接受此行業 + 不會突然封你**」—— 穩定性與政策確定性是最大賣點,價格其次。
- **來源**:XBIZ、AVN 等行業媒體。
- **姿態**:首次接觸**低調、專業**,不出現在公開場合高調宣傳。
- **決策人**:站長 / 營運負責人(此行業層級扁平,老闆常直接管技術採購)。

## 🏟️ 賽事 / 體育(含電競、串流)

### 買方訊號(強 → 弱)
1. **大型賽事臨近**:**2026 世界盃(2026/6–7 進行中)**、歐冠、奧運資格賽、電競 Major → 轉播/資訊平台需要擴容。
2. **拿到轉播權 / 串流版權**的平台 → 必建串流基礎設施。
3. **電競平台 / 體育科技公司融資**。
4. **賽事期間宕機或卡頓被罵**(社群媒體/新聞)→ 事後窗口。

### 跟進打法
- **時機**:**賽前 4–8 週是採購窗口**,賽事開打後只能做災難救援型切入。
- **話術核心**:彈性擴容(賽時 10 倍流量)+ 低延遲串流 + 全球節點。
- **決策人**:CTO / 串流技術負責人(Head of Streaming/Video)。

## 合作夥伴 / ISV 判斷(跨行業)

- **合作夥伴訊號**:支付商/牌照顧問/廣告聯盟宣布進入我們的目標市場、擴大 iGaming/成人客群 → 談轉介分成。
- **ISV 訊號**:白牌博彩平台、遊戲聚合商、風控 SaaS、串流方案商拿到融資或大客戶 → 綁定一家 = 整批下游用量;優先級可等同 A 級客戶。
