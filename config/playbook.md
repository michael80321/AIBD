# 攻堅手冊:開發技巧 + 窗口怎麼找

## 🔑 通用原則

- **融資後 2–6 週 = 黃金窗口**:錢到帳、infra 未定型、對成本敏感。開場永遠從「恭喜」開始,不從推銷開始。
- **一個客戶談組合,不談單品**:先用阻力最小的方案進門(iGaming 用 SMS-OTP、AI 公司用模型折扣),成交後再擴 CDN/雲/GPU。第一張單的目的是拿到信任,不是拿到大單。
- **阿里系引薦鏈**:凡是阿里/螞蟻/阿里雲投資或領投的公司(庫內:AIsa、Tripo AI、Zeroth、AIsphere、Even Realities 等),你作為阿里雲 BD 有天然的 warm intro 路徑——先查該輪的阿里投資團隊窗口,請投後或生態團隊引薦,回覆率比冷觸達高 5–10 倍。
- **同城打包**:出差前先在儀表板按城市篩選,一次約 3–5 家;見面永遠勝過訊息。

## 🎯 窗口怎麼找(按管道)

### LinkedIn(AI / 賽事 / 國際 iGaming 首選)
- 搜尋式:`公司名 + CTO`、`公司名 + Infrastructure`、`公司名 + Head of Engineering`;新創直接找 Co-founder。
- 用 Sales Navigator 篩:公司 + 職稱含 infra/platform/DevOps/procurement;剛融資的公司看「最近發文」的高管,按讚+留言暖場 2–3 天再私訊。
- 連結請求不放推銷詞,只寫:「恭喜完成 X 輪!我在亞太做多雲/GPU 方案,想關注你們的擴張。」通過後再談。

### Email(搭配 LinkedIn)
- 格式猜測:`first@company.com`、`first.last@company.com`;用 Hunter.io / Apollo / Snov 驗證。
- 標題公式:「恭喜{事件}——{具體省錢/解痛點一句話}」;正文 ≤120 字,一個 CTA(15 分鐘通話或給一份對比表)。

### Telegram / Skype(iGaming / 出海圈標配)
- 行業群入口:SiGMA / SBC / Affiliate World 的官方與周邊群、白牌平台商的代理群、支付商群;參展後把名片上的 TG 全加。
- 華語出海圈:TG 搜「出海」「支付」「白牌」「BC」等關鍵詞群組;先潛水看誰在答問題(通常是供應商 BD 或平台技術),私聊從請教開始。
- iGaming 決策人(CTO/Head of Infra)幾乎不回 Email,TG 直接談「接受博彩+高防+節點」三件事,不繞彎。

### 微信 / 脈脈(大陸客戶)
- 脈脈搜公司名找「技術負責人/採購」;透過共同好友請求引薦。
- 展會與線下活動(WAIC、雲棲、ChinaJoy)掃碼加微信是最快路徑;朋友圈持續發「省錢案例」比群發推銷有效。

## 🏭 各行業打法速查

### iGaming
- **決策人**:CTO / Head of Infrastructure;白牌商找商務 VP(綁定=帶整批下游)。
- **開場**:直說三件事——接受博彩、高防容量、目標市場節點。第一單推 SMS-OTP(阻力最小、天天在發)。
- **信任**:展會見面 > TG 熟人引薦 > 冷訊息;此行業只跟「圈內人」做生意,前兩單讓利換口碑。

### AI / 出海 AI
- **決策人**:CTO / 創辦人(Seed–B 輪公司創辦人自己管採購)。
- **開場**:模型折扣進門(「同樣的 token 帳單我幫你打折」零風險易成交)→ GPU → 雲/CDN。
- **素材**:AWS/GCP 對比表常備;引用其融資新聞細節顯示做過功課。

### 成人 / 成人 AI
- **決策人**:站長 / 營運負責人(層級扁平,老闆即採購)。
- **開場**:低調、專業,只談兩點——「接受此內容型態」+「不會突然封你」;絕不在公開渠道提對方行業。
- **管道**:Email + TG;來源圈子:XBIZ 論壇、站長社群(GFY 等)。

### 賽事 / 串流 / 短劇
- **決策人**:串流技術負責人 / Head of Video;短劇公司找海外發行負責人。
- **時機**:大賽前 4–8 週(下一個:亞運,8 月中起);短劇全年皆可,主打「CDN 佔你非內容支出 30–50%,我直接砍價格」。
- **素材**:低延遲實測數據 + 高峰擴容案例。

## 📈 跟進節奏(打完怎麼追)

1. D0 首觸達 → D3 未回:換管道再碰一次(Email→LinkedIn→TG)。
2. D7 未回:發一個「有用的東西」(對比表/行業報告),不催。
3. D14 未回:降級 status=cold,兩個月後看新訊號再啟動;**有回覆立刻升 contacted 並約 15 分鐘通話**。
4. 每次接觸後更新 leads.csv 的 status 與 notes——儀表板 Pipeline 就是你的記憶。
