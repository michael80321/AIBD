## 一律避開(這些人不做基建採購決策)

- HR / Recruiter / Talent / 人力資源 / 招聘
- Support / Customer Service / 客服 / 技術支援(support tier)
- Sales / Account Executive(他們是要賣你東西的)
- Marketing / Affiliate Manager(除非你談的是流量夥伴)
- 行政 / 前台 / info@ / contact@ / support@ 通用信箱

## 🇨🇳 大陸/華語窗口專屬挖法(country=中國/香港,email 幾乎沒用,改用下列)

> 大陸高管少用 LinkedIn/email;用本土平台組合拳,終點都導向微信。

| 平台 | 查得到什麼 | 用途 |
|---|---|---|
| **企查查 / 天眼查** | 法定代表人、主要高管姓名、股東、註冊電話/email、融資、子公司 | 先查到「高管姓名」(合法工商公開資訊);法人常即創辦人 |
| **脈脈** | 具名在職者+職稱 | 用職稱篩到那個人,走共同好友引薦(見 `reports/maimai-lookup.md` 配方) |
| **IT桔子 / 烯牛數據 / 鯨準** | 融資輪次+投資方 | 查領投方 → 走投資人引薦;**阿里/螞蟻投資者 = 你的阿里系引薦捷徑** |
| **BOSS直聘 / 拉勾** | 招聘職缺+常是用人主管本人 | 招 infra/MLOps/運維 = 買方訊號;可從招聘切入認識技術負責人 |
| **微博 / 小紅書 / 知乎** | 創辦人/CTO 親自發文 | 私訊/留言暖場(短劇/AI 圈活躍) |
| **微信** | — | 所有線索的成交終點(展會掃碼/行業群/共同好友) |

**大陸組合拳**:企查查查高管姓名 → 脈脈找到那個人 → IT桔子確認投資方能否引薦(標阿里系)→ 微信成交。**別在大陸猜 email,浪費時間。**

## 挖法鐵律

1. **用職稱過濾工具**(Apollo/Sales Navigator/脈脈 篩 Title),不要用公司通用信箱——通用信箱 100% 進 HR/客服。
2. **寄給那個人本人**(`name@domain`),不寄 `info@`/`support@`。
3. 大陸公司優先脈脈+微信(見各公司脈脈搜尋配方);國際公司優先 LinkedIn+Apollo。
4. 能走**阿里系/投資人/展會**引薦就走,直接點名對的人,跳過所有猜測。
