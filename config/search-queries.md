# 搜尋模板 + 行業媒體清單

- 執行 /bd-daily 時每行業**至少 4 組**,從下列模板挑選並替換佔位符(`{market}`、`{year}` 等),可自行變化措辭。
- 搜尋時**限定近 7 天**(在 query 加當週日期、或用搜尋工具的時間過濾);DDoS/宕機類限近 3 天。
- 英文為主;拉美市場可補西語/葡語關鍵詞。
