# 開發名單:遊戲內容聚合平台商(ISV 綁定型)

> **為何值得專攻**:聚合商用單一 API 把數百家 studio、上萬款遊戲接給下游營運商。**綁定一家聚合商 = 帶進它整批下游 iGaming 營運商**——這些營運商全都要 CDN、高防、雲主機、SMS-OTP。一次談判、整批用量,是本專案 ISV 策略的最高槓桿點。
>
> **切入方式**:找聚合商的 CTO / Head of Infrastructure / VP Partnerships。開場談「你們的整合速度與跨區延遲,加上下游營運商的高防與節點需求,我用多雲組合幫你和你的客戶一起省」。API-first、輕量基建型的(如 Hub88)對成本最敏感,最好談。

## 優先打法(按槓桿與可及性排序)

1. **亞洲聚焦三家先打**:Uplatform、VeliGames、Digitain Asia——地區契合、下游全在你的目標市場,綁定即整批。
2. **Hub88 單獨鎖定**:API-first + 輕量基建 = 對基建成本最敏感,你的多雲比價價值最容易被聽懂。
3. **EveryMatrix 當大魚養**:市場最大、下游最多,但體量大、決策慢——長線經營,先從單一區域節點或高防試單切入。
4. **菲律賓 Future Grid Labs**:搭 PAGCOR 合規潮(7/13 AML 令),用「合規期一併檢視基建」話術。
